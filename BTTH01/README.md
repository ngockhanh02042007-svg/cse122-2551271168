# BTTH01 — Mô phỏng bố cục trang chủ TLU

Dự án HTML/CSS mô phỏng cấu trúc trang chủ [tlu.edu.vn](https://tlu.edu.vn/) theo tư duy bố cục và Flexbox.

## Cấu trúc

- `index.html`: khung trang và nội dung.
- `styles.css`: bố cục, màu sắc, kiểu chữ và responsive.

## Chạy dự án

Mở trực tiếp `BTTH01/index.html` bằng trình duyệt hoặc sử dụng Live Server trong VS Code.
